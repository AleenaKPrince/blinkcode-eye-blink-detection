# BlinkCode Eye Blink Detection System

## Overview
BlinkCode is a real-time eye blink detection and Morse code communication system developed using computer vision and machine learning techniques. The project enables communication through eye blinks by converting blink patterns into Morse code signals.

## Features
- Real-time eye blink detection
- Morse code generation and decoding
- Eye Aspect Ratio (EAR) calculation
- Machine learning based blink classification
- Dataset generation and model training
- Assistive communication system

## Technologies Used
- Python
- OpenCV
- MediaPipe
- Machine Learning
